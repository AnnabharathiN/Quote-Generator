# 💬 Quote Generator – React.js

A simple and interactive Quote Generator built using **React.js**. This application displays inspirational quotes to motivate and inspire users. With a clean and user-friendly interface, users can generate new quotes with a single click.

## ✨ Features

- Display inspirational quotes.
- Generate a new random quote with a button click.
- Clean and simple user interface.
- Responsive design.
- Interactive button hover effects.

## 🛠️ Technologies Used

- **React.js** – Frontend library
- **JavaScript** – Application logic
- **HTML5** – Structure
- **CSS3** – Styling


## 📚 What I Learned

- Building reusable components with React.
- Managing state using React Hooks.
- Handling button click events.
- Working with JavaScript arrays and random values.
- Styling React components using CSS.
